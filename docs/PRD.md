# 사이트 설계도(PRD) — 김종화 목사 | 토론토 갈릴리 장로교회

작성일: 2026-11-10 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
토론토 갈릴리 장로교회 김종화 목사의 사이트로, 교회 홈페이지와 설교 유튜브 영상을 연결하고 신앙상담·문의·기도요청을 받는 곳.

## 2. 손님
- 누가: 다닐 교회를 찾는 토론토 한인
- 어디서 알고 오나: 구글 검색 (예: "토론토 한인교회")

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 예배 시간과 위치
2. 목사님은 어떤 분인지 (소개와 설교 분위기)
3. 자녀·청년 부서가 있는지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 유튜브 설교 영상: 주일예배 설교 (채널 @TorontoGalileeChurch)
- 교회·예배 사진: 있음 (파일은 만들 때 받기 — 미정)
- 목사님 약력·소개글: 있음 (내용은 만들 때 받기 — 미정, 받은 그대로만 적는다)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 목사님께 문의하기
- 누르면: 문의 폼 (신앙상담 / 문의 / 기도요청 중 골라서 남김)

## 6. 페이지 구성 (위에서 아래로)
한 장짜리 페이지 + 관리자 페이지(/admin)

1. 첫 화면 — 한 문장 + [목사님께 문의하기] 버튼 + 예배 시간 바로가기
2. 예배 안내 — 예배 시간표, 부서(유아유치부·아동부·청소년/청년부), 위치(1183 Davenport Rd.)와 전화번호
3. 목사님 소개 — 사진, 약력·소개글 (받은 그대로)
4. 설교 영상 — 최근 주일예배 설교 영상 + 유튜브 채널로 가는 버튼
5. 교회 사진 — 예배·교회 사진 몇 장 + 교회 홈페이지로 가는 버튼
6. 후기 자리 (비워 둠)
7. 문의 폼 — 신앙상담 / 문의 / 기도요청

## 7. 문의 폼에서 받을 것
- 종류: 신앙상담 / 문의 / 기도요청 (하나 고르기)
- 이름, 연락처
- 내용
- 이름 없이 남기기 (선택): 체크하면 이름·연락처 없이 보낼 수 있다. 기도요청을 부담 없이 남기기 위한 것이며, 이 경우 답장은 받을 수 없다고 안내한다.
- 개인정보 수집·이용 동의 (필수, 이름 없이 남길 때는 해당 없음)

- 온라인 헌금 (결제 기능)
- 회원가입·로그인

## 10. 첫 화면 한 문장 후보
1. 토론토에서 함께 예배드릴 교회를 찾고 계신가요? 갈릴리 장로교회가 기다립니다.
2. 말씀으로 위로받고, 함께 기도하는 교회 — 토론토 갈릴리 장로교회 김종화 목사입니다.
3. 고민이 있으신가요? 신앙상담과 기도요청을 편하게 남겨 주세요.

## 11. 다음에 할 것

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. (9번이 '예'일 때) 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
